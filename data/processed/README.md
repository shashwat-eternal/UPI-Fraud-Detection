Intermediate processed datasets are regenerated by running the notebooks in order
(they are excluded here to keep the download small):

    notebooks/02_preprocessing.ipynb        -> X_train_balanced.csv, X_test.csv, etc.
    notebooks/03_feature_engineering.ipynb  -> X_train_final.csv, X_test_final.csv (used by all models)

Or from the command line:
    python src/data/preprocess.py
    # then open 03_feature_engineering.ipynb and Run All
